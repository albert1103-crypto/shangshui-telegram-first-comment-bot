# SHANG SHUI Telegram First Comment Bot

See [README_TH.md](./README_TH.md) for the Thai setup guide.

This Cloudflare Worker comments on automatic channel forwards from `@vieclamsrilankashangshui` inside its linked Telegram discussion group.

## Required secret

```text
BOT_TOKEN
```

Open the deployed Worker root URL once to validate the token and configure the Telegram webhook automatically.
